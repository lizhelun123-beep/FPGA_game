# 流式系统性能与新鲜度分析

先解释观测量，再定位一个可检验的瓶颈。读取已有文件，不连接设备、不重启进程、
不改协议或检测算法。新增采集或硬件诊断需要当前任务的相应授权。

## 先确定日志能证明什么

- 区分传感器/采集率、算法处理率、包编码/入 FIFO 率、线上传输率、完整包接收率、
  UI 采用率和绘制 FPS。只记录 UI 采用场景的日志不能证明 UART 丢包。
- 标明时间戳产生位置和时钟域。接收年龄不是曝光到显示延迟，处理入口不是曝光时间，
  FIFO 写完不是物理线上发完。未经时钟关联，不跨机器时间戳直接相减。
- 分开 leaf（独立阶段）、envelope（包含其他阶段）、span（间隔或排队跨度）、
  event（次数）、meta（关联信息）；只对证据确认互不重叠的阶段求和。

## 累计快照分析

在同一连接、同一已知启动区间选两个完整冻结快照，确认计数、单位和阶段定义一致。
阶段均值为 `Δtotal_us / Δn`；`Δn=0` 时输出未知。累计最大值只能作为截至快照的
历史上界，不能相减生成窗口最大值，也不能从 n/total/max 推导 P95/P99。

附带脚本仅依赖 Python 3.8+ 标准库：

```text
python scripts/analyze.py input.jsonl --contract contract.json
```

路径相对于本技能目录；输出 JSON 到 stdout，输入只读，无有效窗口时退出码 2。
契约结构见 [project-perf-contract.json](references/project-perf-contract.json)。新题目
只需把 `stages` 替换为自己的阶段名与类型，不继承本队的阶段或时间预算：

```json
{"version":1,"stages":{"read_block":"leaf","filter_block":"leaf","loop":"envelope"}}
```

输入每行包含 `connection`（字符串或整数）、`report`（非负整数）、`stage`、
`n`、`total`、`maximum`、`unit`。统计行 unit 必须是 `us`，total 和 maximum
为累计微秒；event 的 total/maximum 固定为零。meta 不参与耗时计算。
同一 report 的行须连续且每个阶段恰好一次；契约应列全冻结快照所需阶段。
`connection` 表示连接分段，不能冒充唯一 boot ID。

脚本拒绝错误类型、单位和计数关系，排除残缺/重复/多余阶段报告，并中断跨连接、
报告回退、累计值回退及可配置启动标记回退的窗口。不跨残缺报告求差，避免越过未知
重启。`boot_marker` 可指定一个 meta 阶段及其中单调增长的整数域；它不等于唯一
启动身份。调用方仍须按已知启动分段，脚本不能识别任意跨启动重放或隐蔽的计数重置。

结果保留最后一个有效窗口、各阶段样本数和累计最大值，同时列出丢弃报告与分段原因。
最后有效窗口可能早于文件末尾，核对其报告编号，不把它称为“当前实时性能”。

## 带宽和服务间隔

按实际包长及串口格式计算线速预算：8N1 的有效上限为 `baud/10 B/s`，
理想线时下限为 `packet_bytes × 10 / baud`。再加入日志、重试和占用余量。
线速下限远短于 FIFO 跨度时，结合 poll_gap、queue_age 和 CPU 长段工作判断，
不能只凭差值认定 UART 硬件慢。不要用提高波特率替代服务间隔证据。

## 闪烁与新鲜度

分别检查“本次完整观测没有对象”“收到无效观测”“暂时没有新包”“断线”和
“超过允许保持期”。接收沉默不会自动成为新的一次缺失观测。可显式显示 STALE
并有界保持最后完整状态；实际安全策略和超时由任务确定，控制/执行器不能照搬
可视化的保持策略。最新值邮箱可避免回放积压，但日志只反映被采用的状态。

先离线重放原间隔，再检查显式移除、无效输入、超时、断线及暂停/锁定；画面稳定
不能作为吞吐提高的证据。最后报告一个主导假设、已有数据、未覆盖范围和最小下一步。

## 提炼来源与已验证效果

本队日志完整报告 24→25 重算得到检测约 450.0 ms、process 包络约 480.0 ms、
poll_gap 约 240.0 ms、FIFO 跨度约 1102.3 ms；这些不是可相加的同类成本。
293 条 UI 场景平均约 0.643 Hz，旧 0.25 s 清空策略预计有 82.7% 时间无模型。
原离线回放验证了保留画面并保持显式 SOURCE 丢失清除；该结论不证明板端达到 8 Hz。
本次新增分析器通过真实保存日志数值比对和合成边界测试；没有重新采集板端数据。
