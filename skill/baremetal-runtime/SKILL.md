# 裸板运行适配

1. 从 XSA/BSP 和链接脚本核对处理器、DDR、栈/堆、外设地址、时钟与中断；复用现有启动流程，不套用 Linux 设备节点或 systemd。
2. 算法保持平台无关；计时、串口、缓存和寄存器经小接口适配。原始帧时间用同一单调时钟，明确计数位宽/回绕。
3. UART 按帧边界和有界队列服务，协议数据与诊断分离；短写/分片不能破坏整包。
4. 区分观测质量失败与设备所有权故障：前者按显示契约继续，后者先保留现场再执行 IP 规定的恢复；不盲目清错、复用活动缓冲或复位全系统。

遇到启动、超时或恢复代码时按需读[裸板检查](references/runtime-checks.md)。先 host/目标编译，再按授权上板；输出具体输入、检查环境、故障边界和最小修复。生成 BOOT 不自动写卡。
