# 实物姿态到权威画面

只沿观测→稳定提交→权威求解→呈现的一条路径修改，不复制检测器或状态机。

1. 从目标配置确认坐标、身份、有限有效边界和有向轴；固定逻辑光源不冒充相机观测。
2. 保留代次、帧序、原始采集时间及会话身份；跨设备先映射时钟，不能用接收时间替换。
3. 适配本关必需类别；缺失/重复拒绝。额外实体按显式规则处理，不能直接丢弃可能参与碰撞的物体。
4. 模型与完整光段原子替换。显示缓存只呈现，旧姿态不重新计分；切关/复位清理归属。

涉及 Portal、姿态筛选或保持时读[场景边界](references/scene-contract.md)。用同段观测核对旋转、遮挡、旧会话和新场景替换；输出修改点与实测/回放范围。粒子仅消费权威结果。
