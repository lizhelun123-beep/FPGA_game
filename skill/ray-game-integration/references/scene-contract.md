# 场景交接边界

- 观测实体和逻辑实体分开：固定光源从配置产生，不能占用相机必检位。以实际类型/ID建立唯一性，额外物体是忽略、阻挡还是报错必须由产品规则决定。
- Portal 有向轴、有效入口/出口与配对策略只在唯一求解器解释；旋转更新方向，不要求先发生位移。Mirror 可为180°等价有限反射面，不能无限延伸。未标定的相机像素不称为毫米。
- 原始 `generation/sequence/captured` 随观测保留；跨设备只用有依据的时钟映射。过期、重复、错关/错会话的观测不能更新权威状态。
- 稳定器只提交一次；画面可以按配置保持，但缓存的采集时间、有效性和归属不刷新。新的完整场景一次替换模型/光路。新关卡/复位按权威会话清理。
- 前端不重新求交或截断完整求解来制造成功；显示预算和粒子效果不得改变计分。两个屏幕复用算法并不代表共享同一会话。

复用用例：当前关只要求三类，输入却有五类时，应按明确实体策略适配再提交；少一个必需类型、重复必需身份仍拒绝。随后回放原地旋转、遮挡、旧关卡和恢复帧，确认旧画面不计分、有效新场景整体替换。
