# 原始事件或串口日志

累计分析脚本只接受其声明的计数格式。事件 JSONL/二进制串口先用目标项目的实际解析器还原消息，不复制一套协议。把片段保留在原顺序，包可能跨多次 read，启动文本也可能混在其中。

先按 `boot/connection/epoch` 分段，再关联关卡、代次、nonce 和原始帧号。分别统计完整解码、板端有效、会话匹配、时钟可用、新鲜度候选、权威采用与显示。没有后端采用记录，只能说接收时准入候选，不能声称实际 UI 已绘制。

每条观测可输出拒绝原因，如：无校时、旧关卡、重复、缺失、PENDING、超过本次项目时限。阈值取实际配置，不把旧日志数值写进通用技能。保留最初错误与上下文，清理后的寄存器不能代替首错。

跨设备年龄只在映射区间成立时计算；例如偏移区间为 `[lo,hi]`，采集时刻区间为 `[captured+lo,captured+hi]`。是否全部落在有效窗口由项目决定；不要只取有利的一端。不把相机时间与电脑接收时间直接相减。

一个控制解析器拒绝计数可能只是收到正常姿态分片。判定坏帧需要完整包的长度/CRC/字段检查，不能从同名日志计数推断。
