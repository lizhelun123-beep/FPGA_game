# AMD/Xilinx 构建交接

从目标工程确认器件、工具版本、入口脚本、处理器和 ABI，只选择请求所需阶段：

- 软件修改：复用匹配硬件→编译/链接→需要时组合启动镜像。
- RTL/BD/XDC 修改：定向检查→相关仿真→需要时实现/导出。
- 制品交接：核对源码/配置/脚本与实际载荷身份；文件同名或哈希一致不能单独证明接口兼容。

新输出使用独立目录，保留原有修改和可恢复制品。编译、打包不自动授权下载、复位或写卡。

只有执行所选阶段时读[阶段与身份](references/build-flow.md)；不扫描全部历史报告。输出命令、输入/输出路径与摘要、执行结果。项目允许仿真作为交付门槛时注明该口径，同时如实说明实际运行环境。
