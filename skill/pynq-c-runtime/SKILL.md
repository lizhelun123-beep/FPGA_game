# Python 编排与 C 算法复用

先保留原算法，把计时、设备访问和入口拆成平台接口；裸板 ELF 需重编译为目标 Linux 程序或共享库。

1. 核对 ARM 位数、端序、浮点 ABI、sysroot 与实际动态库依赖，不用宿主机可加载代替目标兼容检查。
2. 显式绑定函数签名、结构大小、整数宽度和返回码；指针、回调及 Python 存储必须活过 C 使用期。
3. 一个会话拥有算法工作区和设备；非可重入 C 不并发调用。Notebook 和常驻程序使用同一会话实现。
4. DMA 完成且同步后才把 CPU 可读数据交给 C；显示缓存不作为新观测。先停止设备并确认所有权，再释放库/缓冲。

只在实现绑定或迁移时读[ABI 与生命周期](references/c-abi.md)。先用小型 CPU 输入验证边界、错误返回、重入和退出；输出接口、构建命令与验证环境，避免另起一套游戏规则。
